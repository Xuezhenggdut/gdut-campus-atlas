# 航拍与标识细化 15

本轮依据用户在当前会话补充的照片调整，尺寸仍为微缩比例拟合。
用户撤回的“会议中心像工学一号馆”照片不作为依据；会议中心模型和半幅高顶架关系未改。

- 文化活动中心：保留弧形玻璃前厅、前广场和两块草坪；增加礼堂另一侧的短斜玻璃采光顶，修正两级深灰屋面及窗横框。未据斜拍图重定位整个建筑。
- 南门绿篱：以用户最后澄清为准，广东工业大学六字位于中间坡面草坪，左侧草坪放校徽。连续坡面替换旧条带草块，校名和校徽是贴合坡面、略高于草面的深绿植物几何，不是竖立标牌。校徽轮廓来自项目已有官方标识，修剪形态是近似表达。
- 图书馆：正门中轴白栏杆前的字样改为金色浅立体“图书馆”，采用楷体近似照片书法，不宣称为原手迹。
- 科研区道路：创新大道的两处斜接改为平行建筑的直线及直角接头；南段与科研横路对齐。求是路保留南端接口位置，消除斜向过渡。保留入口下穿车道、水岸曲线及所有建筑位置。本轮不是对全校园重做测绘配准。
- 宿舍：强化四道水平栏杆、突出屋面的楼梯间小顶棚；既有暖色组团添加橙色楼板边带，冷色组团仍保留原配色。顶部构件是同类建筑特征近似，并未逐栋确认每座小顶棚的尺寸。
- 教学楼：屋顶外沿、内院边缘、顶棚四面使用四道水平栏杆，增加非外露楼梯楼栋的屋顶小顶棚，并将教号放在对应角部。院落和创谷地面入口仍保持通透。
- 体育区：体育館屋顶降低坡度；泳池保持两池并列、南北长轴的既有配准，补白色开敞柱梁和平台栏杆，并把泳池/体育馆平台接到看台背部。未移动田径场、篮球场或泳池位置，未用实体顶板覆盖水面。

验证：生产构建通过；72 项测试通过，包括建筑避让、道路接口、直角路段、入口通行、坡面绿篱、泳池露天与平台连续性。另检查文化中心、正门、图书馆、宿舍、教学楼、道路及体育区的本地浏览器截图。构建仍有既存的 Three.js 包体积提示。
