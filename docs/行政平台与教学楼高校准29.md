# 行政平台与教学楼高度校准（29）

依据本轮用户提供的行政组团俯拍、平台平视、中央国旗照片，以及“教三、教四、教五、教六建筑高度一样”的明确校正。

## 修改

- 教三至教六统一为同一三层模型高度，中央庭院入口梁架同步降低；保留贯通庭院和两排弧形雨棚。具体米数仍为模型尺度估值。
- 行政平台五处曲线开口重新拟合，四道水平白色栏杆围合；下层增加停车位与车辆，棕榈从开口内的下层地面生长。
- 行政楼、综合楼上部两层房间退让，露出柱廊与露台；连接梁架中部留出真实矩形开口。
- 国旗独立置于入口中轴，彩旗分列两侧；修正右侧旗座与曲线开口的冲突，相关高柱避开平台开口。

- `npm test`：88 项全部通过。
