# 运动区道路与知行大道校正 21

2026-09-22，根据用户提供的普通地图与模型对照截图校正道路和球场。用户同时要求检查穿模。参考为相对位置与走向，坐标仍为示意拟合。

- 篮球场南侧道路沿西南—东北方向通过足球场西北侧空地，再接入知行大道，取消此前先向北、再向东的折角。
- 知行大道沿同一横向轴线延伸到东门及现有外侧道路，求是路、明德路、博雅路的路口同步对齐。东门及其过街标线随道路落位。
- 网球场东侧道路恢复直线。相邻排球场移至其西侧，保持球场边界与路肩的净距；网球场改为三排、每排三片，补横向球网与单双打线。
- 足球场西侧小球场改为两片、四片、三片的阶梯形组团，铺装也随外轮廓退让，西北角和西南角保持开口。
- 回归检查发现篮球场高杆灯靠入新斜路，调整到场地南北侧边缘；俯视检查发现旧西北门落在网球场上，将示意入口移至道路北端路口。

验证：生产构建成功，83 项测试通过。包括完整道路路肩与建筑、球场包络无重叠，高杆灯避让道路和相邻球场，知行大道共线和路口衔接，网球与阶梯形球场的真实网格检查，以及此前看台—连廊净距、泳池露天、平台净空和图书馆外梯检查。浏览器从俯视角复核本次调整范围；检查结论针对这些覆盖范围，不代表全校园摄影测量或任意视角的穷尽验证。
