# 高德地图第一轮校准 · 2026-09-19

本轮已实际操作用户登录的 Codex 内置浏览器高德页面，查看校园普通地图、二维卫星图和倾斜三维卫星视角。原链接为 https://www.amap.com/ssr/search ，没有固定中心点参数。卫星图右下角指北针向上，比例尺先后显示 100 米、200 米。网页版权信息为 Image© DigitalGlobe＆spaceview；页面没有显示可核实的影像拍摄日期。查阅日期不能当作影像日期。

## 实际核对范围与限制

已目视对照南门—创新大道—图书馆、体育馆—中心田径场—文化活动中心、板球场及三个分区的相邻关系。当前三维卫星模式主要表现为地面影像倾斜，不能用于确定建筑高度或立面。全校视野下，小型楼栋及屋顶阴影不足以提供精确地面角点，因此没有将其包装成逐栋测绘校准。

**本轮不是全校位置校准完成。** 主轴为近似对齐，足球场与小球场的尺寸、楼间距、道路和湖岸仍为示意；尚未建立经纬度控制网或量化米级误差。其余重点建筑的精确落点、体育馆占地与看台间距、生活区逐栋角点仍待放大对照。保留 PDF 地面锚点，不直接将卫星图屋顶中心、标签文字位置视为建筑底面。

本地参考截图 `research/amap-audit/satellite-2d.png`，修改前数据 `research/amap-audit/before-campus-data.json`。参考截图不进入 `dist/`、GLB 或交付压缩包，不作为地图贴图。运行仍不依赖高德或互联网。
