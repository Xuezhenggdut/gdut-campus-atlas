# 全校内部道路逐条核对 · 第23轮

核对日期：2026-09-23。对照用户本轮总平面截图，以及本地高清原件 `research/planning-campus-9930141.pdf` 第1页。规划原件为2024批准方案；前面用户明确纠正的现状道路、架空关系和实景照片继续有效。

本轮逐条检查修改前47条道路记录，按西生活区、东生活区、体育区、教学区、科研区、湖区六张叠图核对；修正后为49条记录。编号R01—R47保留修改前编号，R48、R49为新增通道。道路记录不等同于49条独立命名街道，同名横路分别编号。

**结论：已完成这批道路的逐条检查，但仍存在未完成配准的区域，不能称为全校道路已精确还原。** 下表明确区分本轮修改、保留的现状关系和仍有偏差的位置。

## 方法与读图范围

- 各区统一还原到原PDF页坐标，以蓝线叠加模型道路中心线，逐段查看直线方向、折点、端点、路口及建筑间隙。红线、用地边界和控制线不直接当成路面。
- 下表“横向、纵向”指图面方向。原图与场景不是测绘坐标；没有将计算角度、道路宽度写成实测方位角或米数。
- 碰撞筛查包含路面和路肩三角形与已建建筑、球场包围轮廓；架空平台、看台、楼梯、高杆灯等另有现有几何回归测试。不能据此保证所有三角面之间绝无穿模。
- 图中的绿色填充不能直接解释为平地，也不能据此删除湖水。教学连接平台的高度继续依据用户实景纠正。

## 尚未解决的具体偏差

1. **东区医院、东一食堂周边**：当前附属楼锚点与规划轮廓不一致。曾尝试补完整北环路，叠图发现会穿过原图建筑轮廓，已撤回该试画。下一步应先联合校准这些配套建筑与入口，再补道路，不能仅以模型内无碰撞判定正确。
2. **西区北部服务中心附近**：北侧小路不能直接横穿服务中心及体育用地；只落实十五栋绕行段。没有认定北部所有细路均已补全。
3. **体育复合平台、南1门及湖区**：现有整体占地、湖岸仍有局部拟合，与规划不能全部重合。保留用户较新地图的直路、斜路、球场排列及照片中架空层关系，后续需要道路、平台、球场、水体同步校准。
4. **科研区东侧弧路、创新大道偏移及局部横路**：已经检查方向和连接，但局部模型楼体边界与原图体量分割仍有差别；没有把“横平竖直且不穿楼”写成实测位置正确。
5. **生活区间公园与公共道路北端**：仍沿旧河道、公园及外围拟合，局部接点不能仅靠自动吸附解决。

另外，`parkPaths`中的10条公园步道及`promenades`中的2条湖边步道也在本轮范围检查中列为**示意线位，未完成原图逐段配准**：公园西缘、东缘、南环、中环、北部折线、跨园通道及四条短支路；两条湖边步道均依赖当前水岸拟合。它们不混入“47条道路已逐条叠图”的计数，也不宣称已经全部还原。
