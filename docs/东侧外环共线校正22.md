# 东侧外环共线校正 22

2026-09-23，根据用户标注的全校地图，生活东区外侧道路与工学馆外侧道路采用同一条直线，不再分别用局部校准后的折线连接。

保留外侧道路北、南两端的接点，删除两区之间的折点，按同一基准计算中环路交点、知行大道东端及东门位置。生活东区和教学区地面轮廓同步裁到道路边界，消除旧轮廓伸出道路的三角形残片。建筑群内部坐标和楼间距沿用已校准数据，本次修正的是两区共同的外侧道路及边界关系；不据一张截图推断逐栋精确坐标。

验证包括外侧道路跨区共线、中环路交点、知行大道接点、东门衔接及地面轮廓的半平面检查；保留路肩与建筑和球场的重叠检查、灯杆避让、宿舍组团间距、看台连廊净距与架空层净空检查。所有尺寸仍为示意拟合。
