# 实拍细节、天桥与知行大道修订

2026-09-19。参考用户提供的科技楼地图局部、文化活动中心三视角、校园正俯拍、宿舍内外照片及两处道路标注。原图留在 research/revision-references，不随网页和交付包分发。

## 实施内容

- 学生宿舍：每层外走廊、内院走廊、屋顶平台采用四道细横栏杆；房间立面后退，补外柱、窗框、部分空调机位及屋顶楼梯亭。照片未标明楼栋，作为学生宿舍类型参考，没有据此确认每栋的层数与内院尺寸；教师/专家公寓保持单独模板。
- 创新科技楼：B座长条体量，A座贯通中庭。求是A座长条、B座位于后侧；调整示意间距，补楼层连廊。立德A/B改为较矮的独立小窗立面与凹入屋面。结构实验楼增加橙色主体与端部附体。
- 工学馆与实验楼：两处长内院贯穿楼体和屋顶，保留外柱与屋顶横梁；行政楼和综合楼补贯通内院，保留上方格架。
- 文化活动中心：圆弧礼堂顶与后部高屋顶、倾斜玻璃采光带、曲线前厅、右侧内退浅色上层、薄大挑檐、前庭草坪和两侧台阶。
- 广工天桥：中环西路在校园内部道路上方通过，采用带坡道的独立高程。桥下路接东区已有道路；支撑避开下穿通道。高差及坡度仅表达立交关系，不是实测工程尺寸。
- 知行大道：补足球场附近向西至南1门的道路，并接现有环教路。新增南1门搜索地点；它与南门分别保留。新增道路沿球场南侧通过，无球场主体重叠。
