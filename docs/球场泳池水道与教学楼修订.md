# 球场、泳池、水道与教学楼复核

2026-09-19，依据用户新提供的六张截图和本地官方地图分区图修订。

## 本轮改动

- **图书馆西侧球场与环教路**：道路改走球场外侧，保留球场和足球场的相邻关系；球场增加篮球中圈、罚球区、弧线和篮架，不再使用类似泳道的通用线条。球场片数与尺寸仍是示意。
- **体育馆双泳池**：长轴转为南北向，东西并排，泳道线随长轴排列；重做池边平台。邻接的西侧球场南移少量示意距离，以清除平台与场地的覆盖。
- **生活区中央河道**：国医东路、大学城广工二路按宽路表达；河岸与道路使用同组控制线，避免新增道路侵入水面。水面仍有示意变形，不表示实测岸宽。
- **西区外围水道**：补上西侧到南侧的连续水道、滨水内路、外围国医西路和西门连接路。校正西四食堂地面落点，使建筑、滨水路和水道彼此分开。
- **教学一至六号楼**：模块内院真正贯通到地面；屋顶围边、绿色层间带、竖向玻璃带、外缘细柱、楼层连廊与顶部通透横梁分别建模。组团之间增加图示的高位连接梁。保留原地点编号，不把六栋合并成一个地点。

## 检查修正

此前报告的道路检查只包含中心线和较高建筑，漏掉了球场，也没有覆盖实际路宽，不能据此声称所有道路没有重叠。

本轮新增 `scripts/road-surface-audit.ts`：使用与网页相同的路面/路肩三角形，与已建建筑及球场、田径场的地面轮廓逐一相交检查。结果为零冲突。门标记、广场表面允许与道路接触，不纳入此项；外挑屋檐、复杂柱廊、全部构件之间的碰撞不属于这项检查。

17 项自动检查通过，包括两座泳池的长轴和分隔方向、水道不覆盖建筑落点、教学楼内院从上方射线可直达地面。构建通过。六份 GLB 重新导出并加载检查。浏览器俯视及斜视截图为 `output/screenshots/38-` 至 `42-`，本轮没有重新测量 60 秒帧率，也没有手机真机测试。
