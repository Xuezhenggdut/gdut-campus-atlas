# 视频参考与本轮新增功能

参考：[vcqaq 的广西大学 3D 地图演示](https://www.douyin.com/video/7684347410609660838)。2026-09-18 实际查看约 25 秒视频，检查 1、4、8、12、16、20、24 秒画面。作者文字说明其使用 Blender，评论补充使用 Blender CLI；这属于作者自述，未审计其制作工程。

## 画面中能确认的功能

- 全校概览、建筑名称标记、地点列表与分类。
- 南门、图书馆、汇学堂近景，建筑信息卡与多个视角按钮。
- 地标环视及暂停，自动游览与前后切换入口。
- 图层、环境、分享、下载、全屏入口可见，但短视频没有完整演示全部行为。

## 广工网页本轮实现

- 地点详情新增全景、北侧、南侧、东侧、西侧、俯视；使用已校正的校园示意北向，避免给未经确认的立面强行命名“正门”。
- 环绕选中建筑，可暂停；拖动、缩放及键盘操作中断环视。减少动画模式不启动自动环视。
- 自动导览增加上一地标、下一地标。
- 分享当前镜头：链接保存地点、相机、观察中心、视场角和光照；本地地址明确提示仅本机可用。
- 保存当前三维画面为 PNG，不含 HTML 控件。既有 GLB 导出继续保留。
- 保留原有搜索、筛选、图层、昼昏切换、全屏、二维回退与八地标导览。

模型和交互继续使用 Three.js，不要求用户安装 Blender。重点差距仍是建筑还原及景观细节，并非添加按钮即可获得视频的全部视觉质量。

## 分享给别人

将 `dist/` 整个目录部署到静态网站托管后，可发送 HTTPS 链接。接收方只需要浏览器。不能发送 `127.0.0.1` 地址，也不能只上传单个 index.html 而漏掉 assets。

本轮没有执行公网部署，也没有创建账号、购买域名或服务器。公开运行包不包含官网照片缓存、原始 PDF、调试导出接口或研究报告。
