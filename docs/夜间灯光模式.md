# 夜间灯光模式

2026-09-19，新增与日间、黄昏、晚霞并列的「夜间」按钮。链接参数 `light=night` 支持刷新和分享恢复。

后续更新：图书馆内透光及操场高杆灯已进一步修订，当前灯光数量和模型导出状态见 `图书馆内透光与操场高杆灯.md`；本页保留首次夜间模式的检查记录。

夜景包含深蓝渐变星空、冷色环境光与月光、暖色建筑窗灯、宿舍外走廊分段灯、路灯及柔和路面光斑。正门高柱增加灯带，校名石、柱廊和图书馆立面增加局部打光。地图标签与工具栏使用适配深色场景的颜色。

灯光是氛围设计，灯位和实际校园夜间亮灯情况未经逐点核实。道路光斑使用合并几何的渐变叠加，三个局部聚光灯参与真实表面照明；不使用每根路灯各自的实时阴影。夜间资源一次创建并复用，无额外持续动画。低画质材质转换保留窗户发光，异步加载完成后的精细模型也按当前模式亮灯；切回其他模式关闭夜景灯层并恢复非发光玻璃。
