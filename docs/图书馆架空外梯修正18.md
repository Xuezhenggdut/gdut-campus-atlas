# 图书馆架空外梯修正 18

2026-09-22，用户补充航拍并明确指出图书馆外梯下方架空。此修订取代第 17 轮文档中“梯体填实”的处理。

四面外梯改为薄型连续斜梯板与上方踏步，接至柱支撑的上平台；仅保留少量细柱，撤除落地填充体。栏杆随梯跑倾斜，到达上平台后转平，正面宽梯保留中间扶手。外梯平面占地及原有三组正门入口不变。

几何回归测试覆盖四面外梯的下方横向净空、梯板厚度和上平台衔接，并保留原有入口间隙测试。形态依据照片，尺寸仍为示意拟合。

## 第24轮纠正：工大创谷一侧没有外梯

2026-09-23，用户明确指出朝工大创谷景石的图书馆北侧没有台阶。本项取代上文“四面外梯”的范围：移除北侧两组外梯及随梯生成的高平台、支撑柱和扶手，保留底部连续铺地。东、南、西三侧外梯及东侧正门三组入口保留。

回归检查更新为三侧架空外梯，并在原北侧梯位检查不存在高出底部铺地的梯体、上平台或栏杆。85项测试、生产构建通过。
