## 检查与可维护性

- 13 项自动检查通过，覆盖地点来源关联、搜索、模型有限坐标、朝向、图书馆干地包络、两栋临水建筑、环教路连续性、广场平面与工学楼对齐。
- 地面筛查：无主体矩形重叠、无非预期建筑中心入湖、无道路中心线穿过主体。行政楼与综合楼明确列为预期临水建筑。此检查不覆盖所有外挑屋檐、台阶、柱子或道路边缘。
- TypeScript 与正式构建通过。六份 GLB 重新导出，并用 GLTFLoader 重新加载检查几何坐标与材质。全校 GLB 包含建筑和连接格架，不包含道路、水面和植被。
- 浏览器近景与俯视截图从 `output/screenshots/30-` 开始。检查环境为本机内置 Chromium 浏览器，922×898；本轮没有重测 60 秒帧率。历史性能未达 45 FPS 的结论仍保留。

位置修订在 `src/data/campus.ts` 的组团校准段；新道路和湖岸在 `src/data/landscape.ts`；建筑生成器分别为 `researchBuildings.ts`、`pdfDetails.ts`、`southEntrance.ts`、`campusPlazas.ts`，跨楼格架在 `connections.ts`。地点 ID 保持稳定。

教学科研区道路现在使用人工核对的中心线。`scripts/route-roads.py` 仅供旧有生活区与外部道路维护，不能替代本轮明确建立的教学科研区道路。
