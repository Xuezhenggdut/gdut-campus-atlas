# 正门草坡、广场与湖岸道路修正

2026-09-19，根据用户提供的两张高德普通地图圈注和一张卫星俯视图修订。

后续更正：本页截图 58–60 中的柱廊、大讲堂及景石位置由 `柱廊大讲堂景石与晚霞标识.md` 替代；道路和下层广场修订保留。

上一版错误地把团结湖南侧水面扩到校内路两侧，造成穿湖堤路的外观；行政楼阶梯覆盖范围、门前草坡和下层广场也没有正确区分。本次修订替代截图 54 中的湖岸与入口关系。

- 收回南侧湖面边界，校内环教路沿岸边干地延伸，到广场西侧的入口道路汇合。保留更外侧的市政道路和两路之间的绿地。
- 删除原来穿过水面或斜穿入口的示意步道，湖内绿地步道退到干地内，图书馆西侧步道绕水边通过。
- 行政楼前的阶梯和草坡集中到入口道路东侧，四组阶梯之间放置三块并排的绿化坡，保留上层平台。
- 阶梯下方增加连续、平整的铺装广场，南侧边缘随外部道路退界。移动工大广场的位置和铺装范围，避免旧广场压住入口道路。移除误落广场的生成树木，门口短柱收至道路两侧。
