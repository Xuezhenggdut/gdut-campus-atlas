# 球场照明、人车流动与广场树木

2026-09-19，根据用户补充的球场照明说明、交通需求和南门广场卫星截图更新。

四组独立球场补充 16 根双灯头高杆灯，柱高 18 个示意单位。连同此前四处大型运动场，共 32 根灯柱、16 盏场地聚光灯，另有两盏入口景观灯。灯柱避让比赛区域、相邻建筑、道路及水面。灯位和亮度用于示意，未逐点测绘。

外环西路添加 26 辆双向行驶的小汽车；校园主要道路添加 90 位骑行者与 48 位步行学生。共享单车采用美团常见黄色车架、车篮和挡泥板的概括造型，未使用官方标识或精确车型。人物带背包，夜间车辆前后灯发光。对象沿现有道路运动，不模拟真实交通密度、信号控制或车辆避碰。

「地图图层 → 车流与骑行人流」可关闭这些对象及其动画；`traffic=on|off` 可随网址刷新恢复。系统减少动画设置或页面隐藏时停止移动。动态对象使用实例化绘制，更新最多 24 次/秒；开启时持续刷新，不再适用历史静止场景零重复绘制的结论。本轮未重新测量帧率。

南门阶梯下方广场按截图补充 8 棵示意乔木，分为三组错落分布，带小树池，保留阶梯、草坡和右侧校名石前的通行空间。树的数量与位置是对截图的概括，未声称精确清点现场树木。

验证：36 项测试、正式构建及六份 GLB 导出重载通过。浏览器检查日夜球场、外环车辆、黄色骑行者、广场树木与图层开关；关闭后刷新保持关闭，最终恢复开启，无控制台错误。新广场树木包含在南门及全校 GLB 中；动态人车与夜景高杆灯层仅在网页场景中。
