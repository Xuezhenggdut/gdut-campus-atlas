## 本轮实际修正

1. 原版仅旋转图面坐标，留下了斜视网格变形。现在依据 PDF 中两组道路和宿舍排列方向，对示意坐标做仿射校正，并按官方指北针保持北向。手绘图用于检查正交排列和连接关系。此方法基于校园主网格近似正交的假设，**不是对校园进行地理测量或精确正射纠正**。
2. 文化活动中心原落点偏到了前场，正面转错约四分之一圈。落点由 `[666,677]` 修正为 `[667,650]`；曲面玻璃入口朝挑战路，田径场位于背后。独立重建弧形玻璃厅、白色柱廊、整片薄屋檐、礼堂的圆弧高低体块、坡形采光带、两组入口阶梯与前场矩形草坪。
3. 两处田径场长轴转至校园纵向；中心场看台设在体育馆侧。修正膜棚网格朝下导致上方不可见的表面方向。
4. 医院与东区服务中心拆成独立模型；教师宿舍组团按建筑落点纠正。地点 ID 保持不变，现为 95 个地点、93 个建筑/设施记录。
5. 教学楼按长短楼分别细分模块、顶部小体块与连接走廊；宿舍补充 PDF 明确画出的组团连桥。
6. 四座食堂使用各自轮廓：东一为长条加弧端，东二为圆弧前缘，西三为波浪前缘，西四为矩形。会议中心与普通文化楼模型分离，使用不规则曲边轮廓。食堂细部仍主要根据 PDF，未声称具有完整实景验证。
7. 二维地图也改用建筑实际旋转后的地面包络，避免显示不转向的矩形；共享镜头、搜索和稳定 ID 保留。

## 验证与可复查文件

- 8 项自动检查：ID/关联、全名搜索、别名、宿舍独立性、全部生成几何、投影逆变换与北向、活动中心前后关系、两处田径场与主馆长轴垂直。
- 地面筛查采用可处理不同旋转角的矩形分离轴算法；本轮结果：0 主体重叠、0 主体中心入湖、0 道路中心线穿楼。该筛查不包括所有连桥、屋檐与台阶。
- `output/pdf-audit/orientation-audit.json`：92 个有面积对象的地面落点、包络、朝向及证据说明。对未确认的正门方向明确记录未核实，不能把“长轴正确”当作“每一个入口已核实”。
- `src/data/projection.ts`：校正假设、基向量、转换和逆变换。
- `src/scene/culture.ts`：独立的活动中心参数化模型。
- 本机 `http://127.0.0.1:4173/__review/`：PDF、手绘图、9 个实景近似视角以及新模型对照。活动中心提供正面、航拍与入口低视角。

低机位对照范围内减少了随机生成的树木，避免示意树冠遮住被检查的建筑；这些树的位置并非实景逐棵测定。

当前仍是可交互的校园示意模型。其他建筑的逐窗细节、所有入口位置、连廊可通行性、楼层实际高度和地形高程尚未达到精确复原；旧版截图与性能记录保留为历史，不代表最新外观或新版本性能实测。
