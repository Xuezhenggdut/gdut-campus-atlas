# 图书馆内透光与操场高杆灯

2026-09-19，按用户补充的图书馆夜景照片与操场灯柱说明修订。

图书馆原先遮挡灯光的整块外墙板改为有空隙的横向金属格栅，内侧布置分格窗面与细灯带。各层明暗有差异，凹进的露台开口保留更深的窗面；首层补充玻璃入口分格。夜间灯光由窗面和内侧灯带透出，金属格栅不发光，楼板、竖框和露台仍能辨认。取消上一版照向图书馆外墙的单盏泛光灯。日间窗面恢复非发光材质。这里是分层几何和内侧发光的视觉表现，没有模拟真实玻璃折射或完整室内家具。

中心田径场、南侧田径场、图书馆旁足球场及板球场新增共 16 根高杆灯，每根有六个朝场内倾斜的灯头。柱高使用 31–36 个示意单位。每处场地由两盏对角聚光灯交叠照亮，共八盏实际参与表面照明的场地灯，另外保留两盏入口景观灯；均不增加实时阴影贴图。灯柱在比赛场地之外，板球场西侧灯柱避开中环和外环道路。位置、数量和亮度是氛围设计，未经现场逐点测绘。
