- 正俯视和斜视实际渲染检查了 GDUT 的顺序与可见性，调整了膜棚边缘以免遮住字样。
- TypeScript / Vite 构建与 8 项数据、几何和朝向自动检查通过；地面主体筛查仍为 0 重叠、0 中心入湖、0 道路中心线穿楼。
- 南门顶架位于入口广场上方，属于空中构架；主体矩形筛查不把此类跨空构件当作地面封闭建筑。

## 维护

`src/scene/southEntrance.ts` 为南门办公组团、格架、前场与石碑生成器；`src/data/gate-inscription.json` 仅含六个本地生成的中文字形轮廓，不打包字体文件。

`src/scene/sportsLandmarks.ts` 为体育馆、GDUT 看台、膜棚和板球场生成器。字母由座席几何组成，不依赖远程图片或字体。

导出的 `south-gate.glb` 包含行政楼、综合楼、会议中心与前场组团；`gym.glb` 包含主馆、泳池和看台，跑道保留为独立地点；`cricket.glb` 为板球场单体。完整校园 GLB 同步更新。

渲染收尾：静止时不再重复绘制整个校园；相机、模型、光照与图层变化会刷新。低性能设备保留建筑细节，降低材质和树冠开销。60 秒性能复测结果见验收报告及 `output/performance-landmarks.json`，优化前数据亦保留。
